# Hard Mode

Your beautiful demo meets real life.

An agent skill and local browser runner that exercise a web app under repeatable UI stress scenarios and produce visual evidence.

## Status

Planning scaffold. The implementation and installable skill are not available yet.

## Intended first release

Reproduce difficult interface states, inspect failures, and compare the same scenario after a fix.

- Local execution and user-owned output.
- A focused agent skill with the helpers and assets it actually needs.
- A browser view of concrete results.
- Reproducible fixtures and behavioral tests.

This is an independent open-source project. It has no hosted service, account system, or billing.

## Development

There are no build or test commands yet. Commands and installation instructions will be added when the implementation is runnable.
